# 요리 레시피 (인스타 저장함)

인스타그램 저장 컬렉션 **cooking** 에 모아 둔 요리 릴스 301개를 한 곳에서 보려고 만든 페이지입니다.

- 요리 이름·재료로 검색
- 카테고리(한식 / 양식 / 중식·일식 / 디저트·베이킹 / 다이어트·초간단) 필터
- 레시피별 재료 체크리스트(장보기·요리 중 체크, 브라우저에 저장됨)
- 즐겨찾기(브라우저에 저장됨)
- 각 레시피에서 원본 인스타 릴스로 바로 이동

## 파일

- `index.html` — 화면
- `style.css` — 스타일
- `app.js` — 검색·필터·체크리스트·즐겨찾기 동작
- `data.js` — 레시피 데이터(캡션에서 정리한 제목·카테고리·재료·순서 + 원문 캡션)

재료와 조리 순서는 캡션에서 자동으로 뽑아낸 것이라, 비어 있거나 어긋난 부분은 각 레시피의 **원문 캡션**과 릴스에서 확인하면 됩니다.
